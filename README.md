# Darky Website

Eine kleine statische Fursona-Profilseite für GitHub Pages.

## Fursona-Bild einfügen

Lege dein Bild als `darky.png` in denselben Ordner wie `index.html`.
Ideal ist ein quadratisches Bild, z. B. 1000×1000 px.

## Social Links ändern

Öffne `index.html` und ersetze die `href="#"`-Platzhalter durch deine echten TikTok-, Instagram-, VRChat- und BARQ-Links.

## GitHub Pages aktivieren

Öffne im Repository `Settings` → `Pages`.
Wähle unter Deployment den Branch `main` und den Ordner `/ (root)` und speichere.

Danach sollte die Seite unter `https://darkytmc.github.io/darky/` erreichbar sein.
